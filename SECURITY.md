# Security Policy

## Product warning

Bugtrace Recorder is a local full-fidelity capture tool. Recorded sessions and exported
`.bugtrace.zip` files can contain passwords, tokens, cookies, URL parameters, page text, and
screenshot pixels. Treat those artifacts as sensitive. Do not upload them to public issues,
pull requests, or untrusted services.

## Supported versions

Security fixes target the latest GitHub Release of each extension. Older versions may be
asked to upgrade before a report is investigated.

## Reporting a vulnerability

Use GitHub's **Security** tab and choose **Report a vulnerability** to send a private report.
Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Include the affected extension and version, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days. Confirmed issues will be
coordinated privately until a fix or mitigation is available.
